# Amitay Keisar — Portfolio

Personal portfolio site for Amitay Keisar, a full-stack developer shipping products across TypeScript, Kotlin, Rust & Python.

## What This Is

A single-page portfolio showcasing shipped products, skills, and background — built as an experience, not just a page. The site opens with a cinematic intro sequence where a logo assembles, flips like a coin to the navbar, and reveals the site beneath. Every section uses WebGL shaders, glass-morphism surfaces, and choreographed animations to create a cohesive visual identity rooted in a dusk mountain palette.

## Stack

- **React 19** + **Vite** + **TypeScript**
- **Tailwind CSS** — utility-first styling with custom liquid-glass design system
- **motion/react** (Framer Motion) — orchestrated animations, 3D transforms, phase state machine
- **@paper-design/shaders-react** — WebGL shaders (GodRays, Water, NeuroNoise) for section backgrounds
- **Supabase** — PostgreSQL for i18n content + portfolio data, Storage for images
- **React Query** — data fetching with 14-day stale time + IndexedDB persistence
